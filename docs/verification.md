# 検証範囲

## 実行したもの

- SKILL.mdのfrontmatter/name/description/compatibilityの形式検査
- `tests/test_helpers.py`の8メソッド
  - 自作2×2 pixel PSDの読取・保存mergedとの比較
  - PackBitsのliteral/repeat/no-op、欠落・サイズ超過の拒否
  - source hash違い、未対応blendの拒否
  - 合成PCMの音量に応じた口状態と無音時の閉口
  - 字幕領域との分離、画面下へ続かない胴体配置の拒否
  - まばたき状態と負時刻の拒否
  - MCP0.8.1のstdio入口、内部player tools無効化、text/JSON例と3tool期待一覧の整合
- 3つの代表依頼のinlineウォークスルー

テストfixtureはプログラム内で作った一般的な画素・音であり、キャラクターの原画・モデル・人の録音は含まない。

## 代表依頼の確認

| 依頼 | 期待する扱い |
| --- | --- |
| 利用条件と既存MCP音声があるローカル動画 | 実長・音量方式・図/字幕の非重複を確認し、公開しない |
| Engineは応答するがnative MCP toolが見えない | EngineとMCPの状態を区別し、直接HTTPをnative生成と呼ばない |
| 別作者の未対応PSDを、前の許可で公開してほしい | 新素材の権利と能力を確認し、無断代用・公開しない |

これは同一作成者の手順読み合わせとローカル機能検査であり、独立エージェントの実行比較やA/B改善率ではない。全OS、すべてのPSD、全MCPクライアント、YouTube等への投稿を検証したものではない。

## 残る制限

PSD helperは意図的に狭い形式だけを扱い、一般的なPSD互換を保証しない。音量口パクは音素同期ではない。ユーザー素材の権利や公開可否は個別判断が必要。
MCPのセットアップは使用例の配布READMEに基づく。実クライアントのtool一覧と実ファイル生成を、利用時に確認する。
