# 素材・音声・来歴

## 別々に確認する

| 対象 | 記録すること |
| --- | --- |
| 音声 | 使用ライブラリ/話者/style、利用規約、実Engine/MCP情報、生成方法、WAV hash |
| キャラクター | キャラクター運営のガイドライン、利用目的、必要な表記 |
| 立ち絵 | 実作者・配布元・素材版・filename/hash、改変/動画利用/再配布の条件 |
| 図・写真・音楽・フォント | 個別の権利と出典。別素材の許諾を自動継承しない |

参考先：

- [VOICEVOXソフトウェア規約](https://voicevox.hiroshiba.jp/term/)
- [東北ずん子・ずんだもんのガイドライン](https://zunko.jp/guideline.html)
- [音源共通規約](https://zunko.jp/con_ongen_kiyaku.html)

VOICEVOXが無料でも、すべての絵や商用利用が無条件に無料になるわけではない。意図した用途で現在の規約を確認する。

表記例は「音声：VOICEVOX:ずんだもん」「立ち絵：実際の作者（実際の素材版）」。
声のcreditと絵のcreditを分ける。未使用の作者名や別版の素材名を付けない。

## 原本と派生物

利用者の元PSD/ZIP・添付画像・音声モデル・認証情報・私的な記録を公開repoへ含めない。
生成した音声/動画を配布できるかも、それぞれの規約と利用者の公開範囲で判断する。

原本、画像crop、sprite合成、最終MP4を別々にhashで対応させる。sourceが変わった後のchecker結果を、古い動画の生成時点へ書き戻さない。

## 何が確認されたか

MCPに接続できたこと、正しい話者が見えたこと、音声ファイルが本当に生成されたことは別の段階。
同様に、画像が読めること、PSD差分が合成できること、口が動くこと、音声と同期することも分ける。

来歴JSONだけでnative MCP呼出しの事実を暗号学的に証明できるわけではない。実tool履歴と実ファイルを根拠にし、単なる自己申告値を検証済みの事実へ昇格させない。

## 公開前

公開対象と公開先を具体化し、利用者の承認を取る。私的なリポジトリ全体の公開やorigin付替えではなく、必要な公開ファイルだけを別のclean historyへ分離する。
コードのMITライセンスは、第三者の立ち絵や音声モデルの再配布許可ではない。
